# TunePeerly 使用手册

TunePeerly（声渡）播放这台电脑上的音频文件，并分享给已配对的电脑。没有账号。本手册对应 0.6.0。0.6.0 是 alpha 测试版，程序的实际效果不保证和本手册的说明一致。

## 安装

GitHub 上发布的版本是 Inno Setup 安装包。它会询问为所有用户安装，还是只为当前用户安装。默认是当前用户，目录为 `C:\Users\<用户名>\AppData\Local\Programs\TunePeerly`，不需要管理员权限。为所有用户安装时，目录为 `C:\Program Files\TunePeerly`，需要管理员权限。数据库和缓存仍在下面写的固定位置，不随安装目录改变。

安装程序不添加防火墙规则。程序第一次开始监听其他设备时，Windows 防火墙可能会询问是否允许 `TunePeerly.exe`。在你使用的网络上允许它。放在另一个路径的程序会被当成另一个程序，需要再允许一次。卸载时会询问是否删除 Windows 为这一份程序创建的规则。同意后，如果卸载本身不是管理员，会再要求管理员权限。

## 添加音乐

在设置的**音乐和下载文件夹**里添加，或把文件夹和音频文件拖进窗口。程序在文件原来的位置读取，不复制，也不转码。

“全部音乐”页的**扫描**和设置里的**重新扫描**会把所有已添加的文件夹再读一遍。新歌会加进来；有变化的歌，或旁边新加、改过的 `.lrc` 文件，会重新读取，其余不变。

移除文件夹只是从 TunePeerly 里移除，磁盘上的文件还在。其中的歌曲仍留在曲库里并标为不可用，标签、封面、收藏、歌单和最近播放都保留。重新添加该文件夹后即可再次播放。

## 播放

底部播放条控制这台电脑自己的队列：播放、暂停、切歌、拖动进度、随机和重复。声音走系统默认输出设备。

在歌单的歌曲条目上右键可以**下一首播放**、**加入队列**、**加入歌单**和**收藏到喜欢的歌曲**等。

播放队列只在这台电脑上，不会同步。

有 LRC 歌词时，点歌词按钮可以跟着歌曲滚动。

## 窗口、托盘和迷你播放器

窗口使用自己的标题栏。设置 → 外观里的**关闭窗口时**决定关闭按钮的行为：

**最小化后显示小窗**和**进入托盘后显示小窗**会在窗口最小化或隐藏到托盘时，在屏幕上留下一条小播放条，上面有封面、播放控制和爱心。两个开关都关掉就没有小窗。拖封面、标题或空白处可以移动。点封面或标题会打开主窗口。右上角的叉只关掉小窗，下次窗口最小化或隐藏时会再出现。

Windows 任务栏缩略图按比例缩小后显示完整封面，并有上一首、播放、下一首和爱心。

## 歌单

歌单是歌曲列表。删除歌单不会删除歌曲。

所有可读取的本机歌曲都会提供给已配对设备。设备配对并连接后，就能看到、播放和下载全部歌曲，之后新加入的歌也一样。只有无痕模式会停止这一点。

## 配对

打开**设备**。配对前必须打开**附近**旁边的**发现附近设备**，否则无法发现设备。

- **发现附近设备**大约每 3 秒宣布一次这台电脑的名字，走 UDP 组播。
- 也可以输入另一台电脑的 IPv4 地址和端口。端口每次启动都会变，那台电脑在设置 → **这台电脑** → **TCP 监听端口**里显示当前端口。
- 配对时，在一台电脑上点**配对**。另一台电脑会显示 6 位配对码，在第一台上输入即可。一个配对码只能用一次，90 秒内有效。输错 3 次后，配对暂停 1 分钟。配对完成前，连接处于等待确认。
- 拒绝一次请求后，对方要等**拒绝后的静默时间**过去才能再请求。这个设置在历史与隐私里。默认是 60 秒，范围是 1 到 86400。你仍然可以主动连接那台设备。
- 拉黑会移除一台设备，之后来自它的数据会被丢弃。
- **移除**会让两边都解除配对：这台电脑删除这台设备保存的密钥并通知它，它也会移除这台电脑，并显示提示。对方不在线的话，会在两边下次连上时收到通知，在那之前它从这台电脑只会收到这条通知。你的其他设备不受影响。要再一起使用，在任一边点**配对**，并输入新的配对码。

**设备**页**附近**下面的**中继服务器**里有四项中继信息：地址、端口、中继的证书标识和 token，标题下方显示中继状态。两台设备都要把对方设为**完全信任**。自己搭中继见[部署中继](relay.zh-CN.md)。

- 配对只在局域网里进行。中继只在已配对的设备之间转发数据，从不配对。请先在同一网络里配对。
- 使用中继时，两台设备要互相设为**完全信任**。设为**每次确认**的设备不会经中继主动去连，只等对方连进来再问你。如果两边都设成**每次确认**，经中继就永远连不上。
- 中继读不到你的数据（端到端 TLS 1.3），但能看到每台设备的中继标识、公网 IP、在线时间，以及谁连谁、传了多少数据。知道中继地址和某台设备中继标识的人，可以看出这台设备在不在线；应用会拒绝所有未配对的设备。详见 [SECURITY.md](../SECURITY.md)。

设置 → **这台电脑**里可以改这台电脑的名称，其他设备看到的就是这个名称。下面是只读信息：**TCP 监听端口**、发现用的 UDP 端口和组播地址、这台电脑广播的局域网 IPv4 地址，最后是**设备标识**。发现关闭时，发现相关的几行显示“已关闭”。TCP 端口不能指定：每次启动或重新打开网络时，系统会自动选一个空闲端口，发现附近设备时会广播这个端口。改其他设置不会换端口。

## 播放另一台电脑上的歌

在线的已配对设备上的任何歌，都可以从那台设备播放。**下载**把原始文件存进下载文件夹（在设置 → 音乐和下载文件夹里设置），并加入这台电脑的曲库。

## 同步

设置里的**同步**（在音乐和下载文件夹之后）。不会自动同步：只有你点发送或覆盖时，副本才会移动。

无痕模式会断开所有设备、停止发现、关掉同步，并停止向其他设备提供这台电脑的歌曲。

| 控制 | 作用 |
| --- | --- |
| 同步给别人 | 把这台电脑的副本发给一台已连接设备，或发给所有已连接设备。 |
| 覆盖 | 向一台在线设备要它的副本，并替换这台电脑上的副本。每次都由你选设备，不会预先选中哪一台。 |

发送总是覆盖，不做合并，也没有冲突处理。每台电脑按项目选择其他设备发送时怎么处理：**直接覆盖**会立刻替换，**先询问**最多等一分钟让你接受或拒绝，**不允许**会拒绝，什么都不改。默认是直接覆盖。发送方会显示每台设备的结果，例如已更新、不允许覆盖、已拒绝、超时或处于无痕模式，并记进通知。15 秒内没有回复的设备显示为没有回复结果。覆盖不询问，也不受这个选择影响，因为这份副本是这台电脑主动要的。

外观同步包括主题、语言、两个小窗开关，以及关闭窗口时的选择。

## 最近播放

最近播放只留在各自的电脑上，不会同步。有已配对设备连接时，**最近播放**页顶部的列表可以切换到那台设备。它的列表只按需要一次，只读显示：不会保存或合并到这台电脑，也不会发回去。其中这台曲库里也有的歌，或已连接设备上有的歌，可以直接播放。那台设备断开后，页面会回到这台电脑的列表。开着无痕模式的设备不分享列表。

## 通知

铃铛打开通知列表。可以在通知滚进视野时标为已读，在打开面板时标为已读，或只在你点开一条时标为已读。清除时可以每次询问，删除未固定的通知，或全部删除。

## 数据留在哪里

数据库在 `%APPDATA%\TunePeerly`。它是加密的，旁边的密钥文件 `db.key` 只有你的 Windows 账户能打开。封面和界面缓存在 `%LOCALAPPDATA%\TunePeerly`。这两个文件夹不能修改。卸载时会询问是否删除它们。

没有账号。同一局域网里的已配对设备直接同步和串流。不在同一网络时，可以经过**设备**页**中继服务器**里配置的中继相遇。两台设备都要把对方设为**完全信任**。
